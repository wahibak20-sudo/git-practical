project structure
├── index.html   # Main structure of the landing page
└── style.css    # Custom styles (Flexbox/Grid, layouts, and responsiveness)

How to run this project ----

1. Apne computer mein ek naya folder banayein.
2. Us folder ke andar `index.html` naam ki file banayein aur apna HTML code usmein paste kar dein.
3. Ek `style.css` file banayein taake aap is HTML layout ko layout aur design de sakein.
4. `index.html` file par double-click karke ise kisi bhi web browser (Chrome, Edge, Firefox) mein open karein.
